# Workforce & Sales Intelligence Dashboard

## Project Overview

An Excel-based sales intelligence dashboard developed to analyze sales performance, regional targets, customer information, and product performance.

The project combines data cleaning, cross-referencing, Pivot Tables, calculated fields, KPI analysis, and dashboard visualization to generate business insights.

## Objectives

- Analyze overall sales performance
- Evaluate regional sales performance against goals
- Identify top-performing products
- Analyze customer and sales data
- Track key business KPIs
- Present findings through an interactive Excel dashboard

## Analysis Performed

- Data cleaning and preparation
- Data integration using XLOOKUP
- Pivot Table analysis
- Calculated fields
- KPI development
- Regional performance analysis
- Product performance analysis
- Monthly sales analysis
- Dashboard creation

## Dashboard KPIs

The dashboard includes key metrics such as:

- Total Revenue
- Best Performing Month
- Top Performing Region
- Highest Selling Product

## Tools & Technologies

- Microsoft Excel
- Pivot Tables
- XLOOKUP
- Calculated Fields
- Data Analysis
- Data Visualization
